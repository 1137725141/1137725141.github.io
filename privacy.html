Privacy Policy

Singapore VPS Backup is a personal application used by its owner.

Google Drive Access

The application uses rclone to create, access, update and delete backup files managed by the application in the owner's Google Drive.

Data Usage and Storage

Google Drive access credentials are stored on the owner's private VPS. File data is used only for backup and restoration purposes.

Data Sharing

This application does not sell or distribute Google user data to third parties.

Data Retention

Backup files remain in the owner's Google Drive until deleted by the owner.

Access Revocation

The owner can revoke the application's access through Google Account settings.
